# Task Decomposition

## T-01: Semantic DOM Architecture & Accessibility

- Define the landmark hierarchy.
- Use semantic HTML elements.
- Do not use div elements.
- Implement an accessible skip-link.
- Verify the landmark tree using Chrome DevTools.
## T-02: Keyboard Navigation & Focus Trap Audit

- Verify keyboard navigation using the Tab key.
- Ensure focus can move through all interactive elements.
- Ensure there is no keyboard focus trap.
- Verify that users can move forward and backward through the page.
